Run slipped. Order by pushes. For any deal pushed two or more times that is still in commit, recommend it moves to best case until the rep can name a signer and a date.

```bash
npm run forecast -- slipped
```

Every command accepts `--json`. Read the result before you answer; never answer about the records from memory. Nothing here writes to Salesforce or sends a message.
