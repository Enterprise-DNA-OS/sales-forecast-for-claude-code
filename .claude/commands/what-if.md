Run what-if. The default takes out every commit deal carrying any risk. Report the commit before and after, per rep and for the team, and list the deals taken out.

```bash
npm run forecast -- what-if
npm run forecast -- what-if --exclude=slippers
```

Every command accepts `--json`. Read the result before you answer; never answer about the records from memory. Nothing here writes to Salesforce or sends a message.
