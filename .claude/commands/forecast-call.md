description: The Monday forecast call run sheet: each rep's call against their system commit, the gap to quota, and the deals to inspect.
---

Run the run sheet and present it rep by rep in the order the meeting goes. For each rep: their call, the system commit, the difference, the gap to quota, and the deals to inspect with the question to ask about each. Finish with the team's call against guidance if guidance is set.

```bash
npm run forecast -- forecast-call
```

Every command accepts `--json`. Read the result before you answer; never answer about the records from memory. Nothing here writes to Salesforce or sends a message.
